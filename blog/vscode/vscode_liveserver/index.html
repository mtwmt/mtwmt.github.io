如何安裝

開始設定

依需求在設定裡更改預設配置

{
  "liveServer.settings.donotShowInfoMsg": true,
  "liveServer.settings.useLocalIp": true,
  "liveServer.settings.donotVerifyTags": true,
}

donotShowInfoMsg 關閉彈出訊息 useLocalIp 使用實體 ip 做為連線位址( 寫 rwd 頁 面時很實用 方便手機瀏覽 ) donotVerifyTags 關閉 html 缺少的 tag 警告
